Install

  1. Use the editor’s Prepare update button, or hold BOOTSEL while reconnecting the module.
  2. Wait for the RPI-RP2 USB drive to appear.
  3. Drag the verified UF2 you downloaded onto that drive.
  4. Wait for the module to restart, then reconnect it in the editor.

Open the legacy editor if you need the previous interface.
