uSEQ Synthesis — UI Playground

Hardcoded HTML/CSS mockups of the synth-node editor surfaces. Use the variant pills to compare options. Companion to docs/design/synthesis-ux-forks.md. Decisions 2026-07-18: cards → A (rail, + togglable per-param scopes off by default); ghosts → B (status strip, hover-expand with actions); autoplay → any interaction resumes, no dedicated action; widgets → knob+slider, Ctrl+click toggles, min/max/step/curve popover; graph → adds composite expand/contract. Normative text: docs/specs/synthesis.md §7.

The core question: how much chrome does a (synth ...) form earn? Variant A keeps the text primary (uSEQ's current gutter philosophy). Variant B restructures the form into rows (strongest for ghost defaults + per-param vis). Variant C is the minimal control. All three render the same two hardcoded forms; note the health states: running, fallback (a param holding last finite value), error.

A: ghosts are first-class citizens pinned after the buffer — impossible to forget, one click to resolve either direction (bring the code back, or kill the sound). "Restore code" is the safety net that makes aggressive screen-tidying feel safe. Sync-document button announces its blast radius before you press it.

B: ghosts live only in a status count (expandable on hover). The buffer stays pristine — but a performer in flow will not read a counter, and the first haunting will hurt. Probably the "expert mode" of A, not a competitor.

The four engine states, and the two that must be loud: suspended (browser autoplay gate — especially the gamepad trap, where the performer's controller cannot grant audio permission) and error (producer death → faded to silence, never a drone).

The running chip doubles as a load meter (audio-thread budget %). Suspended/error pulse; off is inert grey. These states join the existing transport-mode indicator family (transport-none / transport-wasm / transport-both / transport-hardware colour language).

Claiming a default. A ghost row can be touched three ways, escalating in commitment. The key contract: the widget's value is written into the source text — the document stays the truth. Drag/MIDI-learn escalates to the full live-edit wrapper (that's where slots, persistence and MIDI live).
1 · Ghost knob hover a default row
:mod-amt 100 (default) — nothing in the text yet
2 · Click / type materialises a literal
:mod-amt 340 → plain literal written into the form
3 · Drag or MIDI-learn escalates to live-edit
:mod-amt (live-edit 340 :id "k3f" :min 0 :max 2000) CC 74 · ch 1
Alt: slider style same contract, horizontal
:cutoff 1240

The escalation ladder means casual tweaks stay textually cheap (a bare number) and only deliberate performance-mapping pays the wrapper's syntactic cost. Knob vs slider vs bare drag-number is pure taste per param range — the def's declared range powers all three.
